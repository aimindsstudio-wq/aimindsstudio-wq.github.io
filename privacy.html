Privacy policy

Last updated: 13 October 2026

LocalSocialPublisher is a private application used only by the owner of the 8K Nature & Travel HDR channel to publish the owner's own videos to the owner's own YouTube, Facebook and Instagram accounts.

What data the app uses

The app uses Google OAuth to access the owner's YouTube account (upload videos, set thumbnails, manage playlists and comments). Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data from Google APIs is used only to provide the publishing features described above.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the computer removes all stored data.
